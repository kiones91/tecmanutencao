# 01 — Estrutura Fixa e Contábil

## Custo Fixo Mensal da Empresa
- **Faixa:** R$ 9.000 – R$ 13.000/mês
- **Seed para BDI:** ponto médio = R$ 11.000

## Composição do Custo Fixo
- Pró-labore dos sócios (Kiones, Dioleno, Maike)
- Encargos societários
- Software/assinaturas
- Contabilidade
- Infraestrutura administrativa

## Rateio via BDI
```
BDI_hora = CustoFixoMensal / HorasÚteisMês
```
- **Horas úteis/mês (seed):** 320h
- **BDI seed:** R$ 11.000 / 320 = **R$ 34,38/hora**

## Regra de Aplicação
- Todo orçamento deve incluir linha "Custo Administrativo" com BDI rateado
- BDI incide sobre horas de serviço (não sobre materiais)
